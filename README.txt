Roya Agency Questionnaire

Files:
- index.html
- style.css
- app.js

How to run:
1. Keep all three files in the same folder.
2. Open the folder in VS Code and run index.html using Live Server.
3. Complete the required questions and click the final button.
4. A print window opens. In the browser print dialog, choose "Save as PDF" as the destination and save the file.

PDF note:
The export now uses the browser's native print engine instead of html2canvas/html2pdf, because html2canvas was creating a 0px-high canvas and producing blank PDFs. Native browser printing also handles Arabic shaping and RTL layout more reliably. Allow pop-ups for the local site if the print window does not open. Use the browser's Save as PDF destination to create the PDF file.
